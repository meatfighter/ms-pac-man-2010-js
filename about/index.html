Java original, TypeScript PWA port

Ms. Pac-Man 2010

A desktop browser port of the Slick2D Java game, structured to preserve class, method, file, graphics, audio, and gameplay behavior as closely as the web platform allows.

Browser PWA

The playable web app lives under the pwa directory and is built as a single-page desktop browser PWA with a menu shell, saved-state restore, gamepad input, web audio, and offline caching.

Legacy Source

The desktop directory keeps the Java-era project material available for parity checks and archival review, with a Maven-based build and downloadable Java desktop bundle for modern 64-bit machines.

Release Bundle

The build scripts stamp the version metadata, rebuild the PWA under dist/pwa, render this about page at dist/index.html, and add query-string timestamps to release-facing URLs.
